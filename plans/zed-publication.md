# Как добавить сервер в маркетплейс Zed

Zed имеет встроенный каталог расширений (Extension Marketplace). Чтобы ваш сервер появился там для скачивания, нужно обернуть его в расширение Zed:

1. **Создайте расширение:** Вам нужно создать Git-репозиторий для расширения, содержащий файл `extension.toml`. В этом файле настраивается `context_server_command` (команда запуска вашего сервера) и метаданные. Не встраивайте сам бинарник в расширение — оно должно уметь находить его в системе или скачивать.
2. **Протестируйте локально:** Используйте команду `zed: install dev extension`, указав путь к вашей папке с расширением, чтобы убедиться, что сервер корректно запускается и работает.
3. **Отправьте Pull Request:**
   * Сделайте форк официального репозитория реестра расширений: [zed-industries/extensions](https://github.com/zed-industries/extensions).
   * Добавьте ваш репозиторий в виде Git-submodule в директорию `extensions/` этого репозитория.
   * Оформите Pull Request. После ревью командой Zed и успешного слияния (merge) расширение появится в списке загрузок внутри редактора.
